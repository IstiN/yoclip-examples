# music_animation — неоновый вертикальный лирик-клип на yoclip

1080×1920 @ 30 fps · 1520 кадров · 50.67 c · H.264 + AAC.
Музыка: сегмент трека **с 1:40 до конца** (`assets/audio/track_from_1_40.mp3`, 50.425 с).

Всё нарисовано кодом: векторные примитивы + SVG + две сгенерированные текстуры
(силуэт и зерно/сканлайны). Никаких сторонних артов и видео.

## Синк с вокалом

Тайминги — не сетка «на глаз», а **forced alignment** через Gemini 2.5 Pro
(OpenRouter, аудио → JSON с временем каждого слова) плюс полная транскрипция
хука. Результат — `lib/timing.js`:

- `LINES[i]` — `{start, dur, text, words[]}`: границы 16 строк в кадрах и
  локальное время появления каждого слова;
- `lyric(..., {line: i})` в `lib/kit.js` берёт время слов из `LINES`;
- события сцен привязаны к словам: вспышка камеры на «фотку» (кадр 84),
  штамп «ОТКЛОНЕНО» на «сфоткаться», «COPY» на «пиздит», срез микрофона на
  «Выкинь», `(упс)` в самом конце.

Если правите текст/тайминги — правьте `lib/timing.js`, сцены подстроятся.
В куплете текст из исходного плана; хук транскрибирован (проверьте на слух,
модель может ошибаться в отдельных словах).

## Команды (из корня репозитория yoclip)

```bash
# превью в Studio
yoclip preview --project samples/samples/music_animation

# золотой кадр любой сцены (YOCLIP_FRAME — локальный кадр сцены)
YOCLIP_OUTPUT=/tmp/frame.png YOCLIP_FRAME=60 YOCLIP_SCENE=s7 \
  /opt/homebrew/bin/flutter test \
  samples/samples/music_animation/test/yoclip_cli_screenshot_test.dart

# полный MP4 со звуком (~40 с на M-серии)
YOCLIP_OUTPUT=samples/samples/music_animation/out/music_animation_1080x1920.mp4 \
  /opt/homebrew/bin/flutter test \
  samples/samples/music_animation/test/yoclip_render_test.dart
```

4K: поднимите `width/height` в `yoclip.yaml` до 2160×3840 и увеличьте битрейт
в `test/yoclip_render_test.dart` (`videoBitrate`). SVG/текст останутся
векторными, зерно пересчитается пропорционально.

## Заметки по движку (найдено на этом проекте)

- `Row`/`Column` в JSR игнорировали `spacing` — исправлено в
  `flutter_js_widget_runtime/lib/src/renderer/nodes/js_layout_nodes.dart`
  (проброшено во Flutter `Flex.spacing`). Без фикса слова слипались.
- `external:*` картинки в скриншот/рендер-харнесах нужно передавать явно:
  `externalImageBytes` + `externalFiles`, иначе — серая заглушка на весь кадр.
- `at(node, cx, cy)` центрирует по `width/height`; авто-размерные ноды
  (текст, SVG без размеров) задавайте явным `container` с размерами.
- Прогресс-бары и метры — `row`, а не свободный `stack` (последний центрирует
  fill). Цвета: Flutter `#AARRGGBB`, в SVG в этом проекте `#RRGGBBAA`.
- В логе рендера `render error` = красный кадр-заглушка: проверяйте
  `grep "render error"` после каждого прогона.
