# GOAL — music_animation2

## Цель
Концептуальный лирик-клип (lyric video) для грустного рэп/поп-трека о неразделённой любви.
Клип = финал трека, старт РОВНО со строки «И дальше всё в том же духе...» — 194.0 c трека
(заказчик), 194.0 c → 274.97 c, **2429 кадров (80.97 c) @ 30fps**, вертикаль 1080×1920.
Аудио: assets/audio/track_clip.mp3 = track.mp3, обрезан media_trim с 194.0 c, start 0.
Повествование — от лица парня: он звонит ЕЙ, не может дозвониться (пропущенные на ЕЁ экране —
от него, 12 за вечер; её телефоны — «Нет ответа»). Единый тёмный стиль: dark mode,
интерфейсы iOS, неон (ice/violet/red), глитчи, плёнка.

## Музыка и синхронизация
- Источник тайминга: `scenes/music_timing.js` (глобал MT).
  - `media_beats`: BPM 64.59 (conf 0.651) — октавно проверено по онсетам, рабочая сетка **97 BPM**
    (бит 18.557 ф, фаза 40.7 ф трека). Сетка хранится как справочник; УДАРЫ — из реальных
    onsets (strength ≥ 0.7/0.8), `MT.hit()` для киков фона.
  - Секции энергии (low/medium/high) — для динамики.
- **Караоке по реальному транскрипту** (`transcribe_audio`, google/gemini-3.8-flash;
  артефакты: `.yoclip_cache/analysis/track.beats.json`, `track.transcript.txt`):
  65 строк вокала (3:14–4:06 — строки клипа; полный транскрипт с 0:20 в файле).
  Пословный тайминг: интерполяция по длине слов + снап к 8-м долям сетки 97 BPM.
  Рендер — `sung(f, from)` в `lib/kit.js`: слова всплывают (eoBack pop) в момент пения.
- Шкала: кадры сцен = кадры клипа; кадр трека = кадр клипа + `MT.CLIP_START_F` (5790).
  Аудио: `yoclip.yaml → audio.start: 193`.

## Текст
Караоке по транскрипту: строка видна заранее тусклым (C.dim), ТЕКУЩЕЕ слово — ярко-белое
с холодным свечением, чуть крупнее и приподнято (окно = до старта следующего слова),
пропетые — белые; ключевые слова сохраняют свой неон (красные: забил/убил/дней/боль;
ice: телефон/мобилы/звонил/дождь; violet: гитара/туз/микрофон). Слова появляются строго
в момент пения (пословный тайминг транскрипта + снап к 8-м долям сетки 97 BPM).
Кульминация «НЕ ЗАБИЛ!» — на весь экран с шейком, панч на строке 4:06.
