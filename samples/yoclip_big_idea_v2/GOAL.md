# YoClip Big Idea v2

## Цель
Ремейк [Gamma: What's Your Big Idea?](https://www.youtube.com/watch?v=-CU5DdGZdC8) почти покадрово — под YoClip Studio: открывающий вопрос → слово в 3D → «мы поняли» → генерация → промпт → интерфейс генерации → сетка результатов → чат-агент → 3D → курс → сайт → карусель → загрузка → голдены → созвездие → глобус → туннель → финал. Landscape 1920×1080, языки EN/RU, тема фиолетовая + cyan.

## Технические заметки
- `project.js` — единственный источник порядка сцен, анкеров и текстов (en/ru).
- Сцены в `scenes/*.scene.js`, общий код в `lib/animation.js`.
- Порядок: hook → monolith → generate → prompt → deck → zoom → kaleido → chat → space → course → website → carousel → upload → polish → starmap → globe → tunnel → end. Стыки — кроссфейды по 6 кадров (offset -6).
- Голдены `assets/goldens/*.png` — превью результатов внутри интерфейсных сцен; `assets/layers/ridge_*.svg` — параллакс-хребты финала.
- Статус: структура собрана; хвост (course → end) пересобран вручную — идёт визуальная сверка и полировка.
