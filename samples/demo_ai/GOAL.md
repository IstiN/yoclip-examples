# Goal: Create an engaging promotional video showcasing Yoclip AI capabilities.
# Target: Potential users interested in automated, code-driven video editing.
# Style: Tech-forward, clean, dynamic, fast-paced.

## Scenario & Scene Plans

1. **01_intro** (0-5s):
   - Description: Dynamic gradient background with the text "Yoclip" and "I am Yoclip AI."
   - Goal: High-impact brand introduction.

2. **02_code** (5-10s):
   - Description: Visualize a split-screen or code overlay showing that video structure is defined via code.
   - Goal: Emphasize the "code-driven" efficiency and power.

3. **03_animate** (10-15s):
   - Description: Rapid-fire transitions or motion graphics demonstrating smooth easing and movement.
   - Goal: Demonstrate visual quality and animation capabilities.

4. **04_vision** (15-20s):
   - Description: Final summary screen with the call-to-action message: "Your vision, instantly realized."
   - Goal: Provide a strong closing statement.
